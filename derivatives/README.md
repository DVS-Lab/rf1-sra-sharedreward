# Generated derivatives

Large generated data are not tracked by Git.

- `harmonized/`: RF1 grid-verified, AFNI target-smoothed BOLD images.
- `fsl/EVfiles/`: generated three-column EV files.
- `fsl/sub-*/`: rendered FSFs and FEAT L1/L2 trees.
- `qc/`: run-level smoothness, tSNR, coverage, and provenance outputs.

Small reviewed summaries may be copied to `logs/records/` for versioned provenance. Never place canonical BIDS or Linux2 fMRIPrep outputs here.
