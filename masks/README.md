# Masks

This directory retains historical Shared Reward seed and network masks. Filenames alone are not provenance. A mask may be used in production only after its coordinate space, source/citation, thresholding, resampling history, and checksum are documented.

`seed-VS.nii.gz` is the historical ventral-striatum seed. PPI validation is intentionally downstream of the activation and Phase 0 harmonization work.
